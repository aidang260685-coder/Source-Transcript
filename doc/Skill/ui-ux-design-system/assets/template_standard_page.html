Chuẩn Thiết Kế Giao Diện UI/UX Kiên Thành Tín

Bộ nguyên tắc thiết kế toàn diện theo Figma Design Tokens, hệ lưới 8pt, hỗ trợ tối đa Accessibility (WCAG 2.1 AA) và in ấn xuất bản PDF A4.

Linh Kiện Cốt Lõi

1. Typography & Hierarchy

Áp dụng font Montserrat cho toàn bộ tiêu đề và nội dung. Thang tỷ lệ rõ ràng từ Display (48px) tới Caption (12px).

100% Montserrat

2. Color & Contrast Ratio

Hệ màu Brand (#1A56DB) kết hợp thang xám Slate (50-900). Đạt tỉ lệ tương phản tối thiểu 4.5:1 theo chuẩn WCAG.

WCAG 2.1 AA

3. 8pt Spacing Grid

Mọi khoảng cách padding, margin, row-gap đều là bội số của 4px và 8px, đồng bộ hoàn toàn với Figma Auto-Layout.

8pt Grid

4. Frontend ↔ Backend Contract

Dữ liệu JSON đồng bộ, mã lỗi chuẩn RFC 7807, trạng thái Loading, Empty, và Error state được xử lý trọn vẹn.

API Ready
